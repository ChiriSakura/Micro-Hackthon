# 软件契约核对

`semantics_audit.json` 保存了原始 DynaX 软件文件与本轮定点插件的 SHA-256，以及每个配置的核对记录。

对 51 个配置，各运行 256 个共同随机样本与 4 个边界样本，执行原文件中四个实际函数的未修改 AST。只关闭不参与数值计算的统计记录回调。保持原函数的 softmax、阈值和 torch.topk 行为；没有修改原库。

- 总计 13260 次配置/样本比较。
- 2 次非平局的浮点/LUT 选择差异，均来自 Sanger 阈值附近：threshold=1/256 的 case 124、threshold=4/256 的 case 250。
- 其余非完全一致的 mask 来自等分数 Top-k 的合法平局选择；按每块/整行的所选分数多重集合识别并单列。
- 使用相同定点选择 mask 时，LUT 加输出截断相对浮点稀疏输出的最大误差为 1.013226 个 Q8 ticks，约 0.003958 输出单位。

这些结果说明插件明确实现了所声明的定点近似，不能被表述为所有配置都与原浮点算法逐位相同。独立硬件 E2E 检查定点契约；最终质量限制另与相同输入的浮点 dense-softmax 比较，包含上述近似造成的误差。
